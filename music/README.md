# Music

Drop royalty-free .mp3 tracks here to replace the built-in ambient pad.

- `music/*.mp3`: used for any mood
- `music/<mood>/*.mp3`: used only for that mood (`warm`, `sad`, `tense`, `curious`, `uplifting`)

Safe sources: YouTube Studio → Audio Library (filter "Attribution not required"), Pixabay Music.
Do not use copyrighted songs. Shorts with claimed music can be blocked or demonetised.
